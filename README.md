**«Ведущий для Мафии»** — это мобильный цифровой помощник для ведущего классической настольной игры «Мафия». Приложение берет на себя всю рутину: автоматизирует подсчет времени, ведение протокола голосований, распределение ролей и учет ночных действий игроков, позволяя ведущему сосредоточиться на атмосфере игры.

Проект разработан на движке **Godot Engine** и оптимизирован для мобильных платформ, включая отечественную **ОС «Аврора»**.

## ✨ Функционал и Особенности
* 🃏 **Гибкая настройка ролей:** Поддержка классических и специальных карт (Мирные, Мафия, Дон, Шериф, Доктор, Путана, Маньяк и др.).
* ⏱ **Умный таймер:** Встроенный секундомер для контроля времени речи игроков (минута на оправдание, фолы, протесты).
* 📝 **Цифровой блокнот (Протокол):** Удобная фиксация голосований, выставленных кандидатур и набранных фолов.
* 🌙 **Пошаговая «Ночь»:** Интуитивный интерфейс для фиксации выборов мафии, проверок Шерифа и лечения Доктора. Автоматический расчет итогов ночи.
* 📱 **Адаптивный UI:** Интерфейс разработан специально под вертикальные экраны смартфонов для удобного управления одной рукой.
